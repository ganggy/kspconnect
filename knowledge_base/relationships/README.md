# ความสัมพันธ์ระหว่างตารางหลักใน HOSxP

## ภาพรวม

เอกสารนี้อธิบายความสัมพันธ์ระหว่างตารางหลักๆ ใน HOSxP เพื่อให้เข้าใจว่าข้อมูลเชื่อมโยงกันอย่างไร

## ตารางเชื่อมโยงหลัก

```
┌─────────────────────────────────────────────────────────────────┐
│                         patient (hn)                            │
│                    ข้อมูลผู้ป่วยหลัก                             │
└─────────────┬───────────────────────────────┬───────────────────┘
              │                               │
    ┌─────────▼─────────┐         ┌───────────▼──────────┐
    │   ovst (vn)       │         │   ipt (an)           │
    │  ผู้ป่วยนอก        │         │  ผู้ป่วยใน           │
    └─────────┬─────────┘         └───────────┬──────────┘
              │                               │
    ┌─────────▼─────────┐         ┌───────────▼──────────┐
    │ opdscreen (vn)    │         │ iptdiag (an)         │
    │ ovstdiag (vn)     │         │ iptbedmove (an)      │
    │ opitemrece (vn)   │         │ iptdrugorder (an)    │
    │ lab_head (vn)     │         │ opitemrece (an)      │
    └───────────────────┘         └──────────────────────┘
              │                               │
              └───────────────┬───────────────┘
                              │
                    ┌─────────▼─────────┐
                    │  opitemrece        │
                    │ (vn หรือ an)       │
                    │  + icode           │
                    └─────────┬─────────┘
                              │
                    ┌─────────▼─────────┐
                    │  drugitems (icode) │
                    └───────────────────┘
```
