# โมดูลการเงิน (Finance Module)

## ภาพรวม

โมดูลการเงินใน HOSxP เป็นส่วนที่จัดการข้อมูลค่าใช้จ่ายทั้งหมดที่เกิดขึ้นจากการรักษาพยาบาล ตั้งแต่การบันทึกรายการค่ารักษา การคำนวณค่าใช้จ่าย การรับเงิน ไปจนถึงการออกใบเสร็จรับเงิน

สิ่งที่โมดูลนี้ครอบคลุม:
- **การเงิน** — การรับเงิน การคืนเงิน การวางบิล
- **ค่ารักษาพยาบาล** — รายการค่ายา ค่าห้อง ค่าบริการ ค่าตรวจ
- **ใบเสร็จรับเงิน** — การออกเลขที่ใบเสร็จ และการติดตามสถานะการชำระเงิน

---

## ตารางหลัก (Main Tables)

| ตาราง | ชื่อภาษาไทย | ความสำคัญ |
|---|---|---|
| `opitemrece` | รายการค่าใช้จ่ายต่อครั้งมา | ตารางหลักเก็บรายการค่ารักษาทั้งหมด |
| `finance_deposit` | เงินมัดจำ | บันทึกเงินมัดจำของผู้ป่วยใน |
| `ovst_finance` | ข้อมูลการเงินของการมารับบริการ | สรุปข้อมูลการเงินต่อ VN |
| `income` | รหัสรายได้ | ตารางอ้างอิงประเภทรายได้ |
| `rcpt_print` | ใบเสร็จ | ข้อมูลใบเสร็จรับเงิน |
| `ovst_rcpt` | การรับเงินต่อ VN | บันทึกการรับเงินต่อการมา |

## กระบวนการทำงาน (Flow)

```
1. ผู้ป่วยมารับบริการ (visit)
         |
         v
2. แพทย์/พยาบาลสั่งยา สั่งตรวจ สั่งบริการ
         |
         v
3. ระบบบันทึกลง opitemrece (รายการค่าใช้จ่าย)
   - แต่ละรายการมี sum_price (ราคารวม)
   - ระบุ income (รหัสประเภทรายได้)
   - paid = 'N' (ยังไม่จ่าย)
         |
         v
4. การเงินตรวจสอบและรับเงิน
   - อัปเดต paid = 'Y'
   - บันทึก rcpt_no (เลขที่ใบเสร็จ)
   - อัปเดต ovst_finance (สรุปยอด)
         |
         v
5. ออกใบเสร็จรับเงิน
```

---

## รหัสสถานะที่สำคัญ

| ฟิลด์ | ค่า | ความหมาย |
|---|---|---|
| `paid` | 'N' | ยังไม่ได้รับเงิน |
| `paid` | 'Y' | รับเงินแล้ว |
| `paid` | 'C' | ยกเลิก |
| `confirm` | 'N' | ยังไม่ยืนยันรายการ |
| `confirm` | 'Y' | ยืนยันรายการแล้ว |
