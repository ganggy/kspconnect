# HOSxP Knowledge Base

## คำแนะนำการใช้งาน

เอกสารนี้เป็นแหล่งอ้างอิงสำหรับผู้ที่ต้องการเข้าใจโครงสร้างฐานข้อมูล HOSxP เพื่อใช้ในการพัฒนาโปรแกรมเสริม สร้างรายงาน หรือทำ Vale

## โมดูล

| โมดูล | คำอธิบาย | ลิงก์ |
|-------|---------|-------|
| **01-Patient** | ข้อมูลผู้ป่วยหลัก (HN, ชื่อ, ที่อยู่, สิทธิ) | [เข้าชม](01-patient/) |
| **02-OPD** | ผู้ป่วยนอก (VN, คัดกรอง, วินิจฉัย) | [เข้าชม](02-opd/) |
| **03-IPD** | ผู้ป่วยใน (AN, ย้ายเตียง, วินิจฉัย) | [เข้าชม](03-ipd/) |
| **04-Drug** | เภสัช (ยา, สั่งยา, จ่ายยา) | [เข้าชม](04-drug/) |
| **05-Finance** | การเงิน (ค่ารักษา, ใบเสร็จ) | [เข้าชม](05-finance/) |
| **06-Lab** | ห้องปฏิบัติการ (สั่ง lab, ผล lab) | [เข้าชม](06-lab/) |
| **Relationships** | ความสัมพันธ์ระหว่างตาราง | [เข้าชม](relationships/) |

## Key Identifiers (ตัวระบุหลัก)

| ตัวระบุ | อยู่ในตาราง | ความหมาย |
|---------|-----------|---------|
| **HN** | `patient.hn` | เลขประจำตัวผู้ป่วย |
| **VN** | `ovst.vn` | เลข Visit (ผู้ป่วยนอก) |
| **AN** | `ipt.an` | เลข Admit (ผู้ป่วยใน) |
| **icode** | `drugitems.icode` | รหัสยา/รายการ |
| **lab_order_number** | `lab_head.lab_order_number` | เลขใบสั่ง Lab |

## ความสัมพันธ์เบื้องต้น

```
patient (hn)
    ├──→ ovst (vn) ──→ opdscreen, ovstdiag, opitemrece, lab_head
    └──→ ipt (an) ───→ iptdiag, iptbedmove, iptdrugorder, opitemrece
```

## ตารางกลางที่สำคัญที่สุด

- **`opitemrece`** - ตารางค่ารักษาทั้งหมด (ยา, lab, x-ray, ค่าห้อง, ค่าอาหาร) เชื่อม OPD/IPD/Drug/Finance

## เริ่มต้นใช้งาน

1. เข้าใจ [Patient Module](01-patient/) ก่อน - เป็นพื้นฐานของทุกอย่าง
2. ศึกษา [OPD](02-opd/) หรือ [IPD](03-ipd/) ตามความสนใจ
3. ดู [Relationships](relationships/) เพื่อเข้าใจการเชื่อมโยง
4. ลองใช้ตัวอย่าง Query ในแต่ละโมดูล

## หมายเหตุ

- ฐานข้อมูล HOSxP มีมากกว่า 6,000 ตาราง เอกสารนี้ครอบคลุมเฉพาะตารางหลักที่ใช้บ่อย
- ข้อมูลส่วนบุคคล (ชื่อ, เลขบัตรประชาชน) ถูก mask โดยอัตโนมัติจากระบบ
- ตัวอย่าง Query ใช้ MySQL syntax ตามมาตรฐาน HOSxP
