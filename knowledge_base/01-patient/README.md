# โมดูลข้อมูลผู้ป่วย (Patient Module)

## ภาพรวม

โมดูลนี้เก็บข้อมูลพื้นฐานของผู้ป่วยทั้งหมดในระบบ HOSxP เป็นจุดเริ่มต้นของทุกกระบวนการรักษา ทั้งผู้ป่วยนอก (OPD) และผู้ป่วยใน (IPD)

## ตารางหลักในโมดูลนี้

| ตาราง | คำอธิบาย | ความสำคัญ |
|-------|---------|----------|
| `patient` | ข้อมูลผู้ป่วยหลัก | ⭐⭐⭐ ตารางหลักสุด |
| `patient_address` | รหัสที่อยู่ (จังหวัด/อำเภอ/ตำบล) | ⭐⭐ |
| `patient_pttype` | ประวัติสิทธิการรักษา | ⭐⭐⭐ |

## ความสัมพันธ์เบื้องต้น

```
patient (hn) 
    ├──→ ovst (vn)      [ผู้ป่วยนอก]
    ├──→ ipt (an)       [ผู้ป่วยใน]
    ├──→ patient_address [ที่อยู่]
    └──→ patient_pttype  [สิทธิการรักษา]
```

## Key Identifiers

- **HN (Hospital Number)** - รหัสผู้ป่วยหลัก เชื่อมทุกตาราง อยู่ใน `patient.hn`
- **CID** - เลขบัตรประชาชน อยู่ใน `patient.cid`
- **PTTYPE** - รหัสสิทธิการรักษา อยู่ใน `patient.pttype` (สิทธิปัจจุบัน)

## หลักการทำงานใน HOSxP

1. ผู้ป่วยลงทะเบียนครั้งแรก → สร้าง record ใน `patient` (ได้ HN)
2. มารับบริการครั้งถัดไป → ใช้ HN เดิม สร้าง record ใน `ovst` (ได้ VN)
3. สิทธิการรักษา → เก็บใน `patient_pttype` (อาจมีหลายสิทธิต่อคน)
