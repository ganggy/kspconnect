# โมดูลผู้ป่วยนอก (OPD Module)

## ภาพรวม

โมดูลนี้เก็บข้อมูลการรับบริการผู้ป่วยนอก (Outpatient) ทั้งหมด ตั้งแต่การลงทะเบียนรับบริการ คัดกรอง ตรวจรักษา จนถึงการวินิจฉัย

## กระบวนการทำงาน (Workflow)

```
ผู้ป่วยมารับบริการ
    ↓
ลงทะเบียน → สร้าง record ใน ovst (ได้ VN)
    ↓
คัดกรอง (Screening) → บันทึกใน opdscreen
    ↓
ตรวจรักษา (Doctor) → บันทึกอาการ/วินิจฉัย
    ↓
วินิจฉัย (Diagnosis) → บันทึกใน ovstdiag (ICD10)
    ↓
สั่งยา/สั่ง Lab → บันทึกใน opitemrece
    ↓
จ่ายยา/รับยา
```

## ตารางหลักในโมดูลนี้

| ตาราง | คำอธิบาย | ความสำคัญ |
|-------|---------|----------|
| `ovst` | ตารางหลักของการ visit ผู้ป่วยนอก | ⭐⭐⭐ |
| `opdscreen` | ข้อมูลคัดกรอง ( vital signs, CC, PE ) | ⭐⭐⭐ |
| `ovstdiag` | การวินิจฉัยโรค (ICD10) | ⭐⭐⭐ |
| `opd_department` | รายชื่อแผนก | ⭐⭐ |
| `ovstist` | สถานะ visit | ⭐⭐ |
| `ovstost` | สถานะออก | ⭐⭐ |

## Key Identifiers

- **VN (Visit Number)** - รหัสการ visit ผู้ป่วยนอก อยู่ใน `ovst.vn` เป็นคีย์หลักของทุกกระบวนการในครั้งนั้น
- **HN** - เชื่อมกับตาราง `patient`
- **vstdate** - วันที่มารับบริการ
- **vsttime** - เวลาที่มารับบริการ

## ความสัมพันธ์เบื้องต้น

```
ovst (vn)
    ├──→ patient (hn)         [ข้อมูลผู้ป่วย]
    ├──→ opdscreen (vn)       [คัดกรอง]
    ├──→ ovstdiag (vn)        [วินิจฉัย]
    ├──→ opitemrece (vn)      [สั่งยา/ค่ารักษา]
    ├──→ lab_head (vn)        [สั่ง Lab]
    ├──→ doctor (code)        [แพทย์]
    ├──→ pttype (pttype)      [สิทธิ]
    └──→ spclty (spclty)      [ความเชี่ยวชาญ]
```

## หมายเหตุสำคัญ

- 1 HN อาจมีหลาย VN (มาหลายครั้ง)
- VN สร้างใหม่ทุกครั้งที่มารับบริการ
- `ovst.an` จะมีค่าเมื่อผู้ป่วยนอกถูก admit เป็นผู้ป่วยใน
